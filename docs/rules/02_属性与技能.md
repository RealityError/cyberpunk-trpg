# 属性与技能

## 属性

| 属性 | 用途 |
| --- | --- |
| 智力 | 知识、分析、调查、战术判断。 |
| 反应 | 射击、驾驶、先攻等快速反应。 |
| 敏捷 | 身体协调、闪避、近战、潜行、运动。 |
| 技术 | 修理、医疗、电子、撬锁、制作。 |
| 酷 | 压力下的气场、社交压制、交易、街头处事。 |
| 意志 | 专注、抵抗痛苦、精神韧性。 |
| 幸运 | 消耗点数提高检定结果。 |
| 移动 | 回合内移动距离。 |
| 体魄 | 身体强度、锁喉/投掷伤害、死亡豁免。 |
| 共情 | 交流、察言观色、社交理解。 |
