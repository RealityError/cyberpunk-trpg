# 战斗流程

## 战斗时间

战斗分为轮和回合。

- 每个角色执行一次自己的回合。
- 所有参与者都执行完回合后，一轮结束。
- 一轮约等于 3 秒。

## 先攻

战斗开始时，每个参与者投掷先攻：

```text
反应 + 1d10
```

按先攻结果从高到低行动。

先攻平局时重新掷骰，直到分出高低。

## 每回合行动

每个角色每回合获得：

```text
1 次移动动作 + 1 次其他动作
```

## 移动

普通移动距离：

```text
移动属性 x 2 米
```

如果使用网格地图：

```text
移动属性 = 可移动格数
```

允许斜向移动。

不能停在格线之间。

## 困难移动

以下移动消耗翻倍：

- 游泳
- 攀爬
- 助跑跳跃

原地跳跃距离按助跑跳跃的一半处理。

## 倒地

倒地角色不能使用移动动作。

需要先使用起身动作，才能重新移动。

## 常用动作

| 动作 | 说明 |
| --- | --- |
| 攻击 | 发起近战或远程攻击。 |
| 锁喉 | 对已擒抱目标造成体魄伤害。 |
| 起身 | 从倒地状态恢复。 |
| 擒抱 | 控制目标、夺取物品或挣脱擒抱。 |
| 延迟动作 | 指定触发条件，将动作留到后续时机执行。 |
| 装填 | 完全装填或更换弹匣。 |
| 奔跑 | 额外执行一次移动动作。 |
| 稳定伤势 | 让目标进入自然恢复流程，或救回濒死目标。 |
| 投掷 | 摔投被擒抱目标或投掷物体。 |
| 使用技能 | 完成一个快速技能任务。 |
| 使用物品 | 操作不需要技能检定的物品。 |

## 拆分移动

角色可以在移动中间执行其他动作，然后继续移动。

ROF 为 `2` 的攻击可以拆分为两次攻击，并穿插在移动之间。

ROF 为 `1` 的攻击占用整个攻击动作，但攻击前后仍可移动。
