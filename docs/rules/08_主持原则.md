# 主持原则

## 基调

游戏应保持以下基调：

- 生存压力
- 技术冷感
- 街头危险
- 组织压迫
- 偏执与不信任
- 风格、态度和边缘生活

## 使用人生路径

GM 应优先使用角色人生路径制造冲突和动机。

可使用的切入点：

- 朋友受到威胁。
- 敌人采取行动。
- 家人、恋人或旧关系被卷入事件。
- 角色珍视的东西成为代价。
- 角色过去的选择带来后果。

## 任务设计

任务不应只依赖“有人雇你干活”。

更好的任务动力来自：

- 角色自己的目标。
- 角色的人际关系。
- 敌人的报复。
- 生存资源。
- 街头名声。
- 被迫卷入的危机。

## 场景处理

当玩家选择解决方式时，默认支持：

- 暴力
- 潜行
- 交涉
- 玩家提出的其他方案

对于玩家提出的非常规方案，优先顺势推进，再用合理的技能检定、代价或后果制造张力。

## 难度升级

简单计划可以先使用 `DV15` 作为挑战。

关键节点或最终阻碍可以提高到 `DV17`。

如果能把挑战连接到角色的人生路径，优先这么做。
