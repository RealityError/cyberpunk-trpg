# 角色卡

## 基础字段

角色卡至少包含：

- 代号或姓名
- 职业
- 属性
- 技能
- 生命值
- 重伤阈值
- 死亡豁免相关数值
- 武器
- 护甲
- 职业能力
- 赛博组件
- 装备
- 人生路径记录
- 备注

## 技能总计

角色卡上的技能总计：

```text
关联属性 + 技能等级
```

进行技能检定时：

```text
技能总计 + 1d10 + 修正
```

## 武器字段

武器至少包含：

- 名称
- 类型
- 伤害
- 弹药
- ROF
- 备注

伤害通常表示为 `Xd6`。

## 护甲字段

护甲至少包含：

- 名称
- SP

`SP` 用于减少受到的伤害。护甲吸收伤害后可能发生损耗。

## 赛博组件字段

赛博组件至少包含：

- 名称
- 效果
- 是否需要主动启用
- 对角色属性、技能或状态的影响

## 职业能力字段

职业能力至少包含：

- 职业名称
- 能力名称
- 效果
- 触发条件
- 持续时间或限制

## 预设职业

Easy Mode 中的预设角色职业包括：

- 摇滚小子
- 佣兵
- 技工
- 技医
- 媒体人
