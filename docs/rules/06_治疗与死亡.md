# 治疗与死亡

## 死亡豁免

角色处于濒死状态时，每个自己回合开始都要进行死亡豁免。

死亡豁免：

```text
1d10 + 当前死亡豁免惩罚
```

如果结果低于体魄，角色继续存活并照常进行本回合。

如果结果不低于体魄，角色死亡。

如果 d10 掷出 `10`，自动失败。

每进行一次死亡豁免，死亡豁免惩罚增加 `1`。

死亡豁免惩罚持续累积，直到角色通过稳定伤势恢复到 `1 HP`。

## 稳定伤势

稳定伤势需要一个动作。

检定：

```text
技术 + 急救或医疗 + 1d10
```

稳定 DV：

| 状态 | DV |
| --- | ---: |
| 轻伤 | 10 |
| 重伤 | 13 |
| 濒死 | 15 |

成功稳定后，角色可以进入自然恢复。

## 自然恢复

稳定后，如果角色每天大部分时间保持轻松活动或休息：

```text
每日恢复 HP = 体魄
```

如果角色勉强活动，当天不恢复 HP，并需要重新稳定伤势。

## 重伤处理

重伤处理分为：

- 应急处理：暂时移除伤势影响，通常持续到当天结束。
- 治疗：永久移除伤势影响。

应急处理通常耗时 1 分钟。

治疗通常耗时 4 小时。

角色不能对自己进行完整治疗。

严重伤势可能需要外科手术。外科手术能力来自对应职业能力。
