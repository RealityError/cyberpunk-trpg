# 人生路径

人生路径用于生成角色背景、关系、动机和剧情钩子。

生成方式：

- 按表投掷对应骰子。
- 玩家也可以直接选择符合角色概念的结果。
- 如果掷出的结果不适合角色，可以改选。

## 朋友数量

掷：

```text
max(1d10 - 7, 0)
```

对每个朋友掷 `1d10` 或选择其关系。

## 敌人数量

掷：

```text
max(1d10 - 7, 0)
```

对每个敌人生成：

- 敌人是谁
- 仇恨原因
- 再次碰面时对方会如何行动

## 悲恋纠葛数量

掷：

```text
max(1d10 - 7, 0)
```

对每段悲恋生成结束原因。
