# 规则索引

本目录是项目的默认规则来源，用于指导后续功能设计、数据建模和规则实现。

约定：

- 不在规则条目中记录 PDF 文件名、页码或来源映射。
- 只整理实现需要的规则口径，不保留排版、插图说明和原书长段叙述。
- 当规则文本与代码行为冲突时，先更新本目录，再修改代码。
- 规则中出现的英文缩写保持原样，例如 `DV`、`ROF`、`HP`、`SP`。
