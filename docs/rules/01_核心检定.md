# 核心检定

## 什么时候检定

角色尝试有风险、有压力、存在失败后果，或结果不确定的行动时，进行技能检定。

明显简单、没有实际失败压力的行动不需要掷骰。

## 基础公式

```text
属性 + 技能 + 1d10 + 修正
```

如果角色没有对应技能，只使用对应属性：

```text
属性 + 1d10 + 修正
```

## 对抗检定

双方都掷：

```text
属性 + 技能 + 1d10 + 修正
```

结果较高者获胜。平局时，防御方或被动方获胜。

## 固定难度检定

行动由环境、工具、时间压力或任务复杂度决定难度时，GM 设定 `DV`。

检定总值需要超过或达到 `DV` 才成功。本项目实现中统一按 `total >= DV` 判定成功。

## 难度值

| 难度 | DV |
| --- | ---: |
| 日常 | 13 |
| 困难 | 15 |
| 专业 | 17 |
| 英勇 | 21 |
| 难以置信 | 24 |

## 大成功

如果基础 d10 掷出 `10`：

```text
总值 = 属性 + 技能 + 10 + 额外 1d10 + 修正
```

额外 d10 不继续触发大成功。

## 大失败

如果基础 d10 掷出 `1`：

```text
总值 = 属性 + 技能 + 1 - 额外 1d10 + 修正
```

额外 d10 不继续触发大失败。

## 再次尝试

同一角色在同一条件下失败后，不能无条件重复尝试。

再次尝试需要情况发生变化，例如：

- 花费更多时间。
- 使用更好的工具。
- 获得他人协助。
- 先完成一个合理的关联技能检定。

## 关联技能检定

一个技能可以为后续另一个合理相关的技能创造优势。

项目默认口径：

- 成功的关联检定为后续一次相关检定提供 `+1`。
- 关联加值不叠加。
- 是否关联由 GM 判定。

## 花费额外时间

角色可选择花费约四倍时间，获得后续一次相关检定 `+1`。

## 幸运

角色在掷骰前可以消耗幸运点。

每消耗 `1` 点幸运，本次检定获得 `+1`。

幸运池在每次开团时恢复到幸运属性值。
